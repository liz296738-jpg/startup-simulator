# 创业模拟器

网页版 0.3.0。100 张 LOOTDROP 关联案例卡、20 个原创经营剧本，以及玩家自建公司的 DIY AI 连续剧情。

## 使用
- 选择预设剧本，完成 12 个月的经营决策、记账和复盘。
- 或创建 DIY 公司，填写想法、目标客户、商业模式、启动资金和创业目标。
- 在设置中输入自己的 DeepSeek API Key。可生成本月剧情、与角色讨论、提出四个选项以外的行动。
- DIY 剧情保留人物与线索，已生成章节随存档缓存。初始24个月，存活后可按年继续，最长120个月。
- iPhone / iPad 使用 Safari 打开网址，通过分享菜单添加到主屏幕。安卓和电脑也可直接通过网址使用。

## 本地启动
使用 Node.js 24，无第三方运行依赖：

```sh
npm test
npm start
```

打开 `http://localhost:10000`。部署时监听 `0.0.0.0` 和环境变量 `PORT`。

## Render
连接本 GitHub 仓库，新建 Node Web Service：
- Build Command：`npm test`
- Start Command：`npm start`
- Health Check：`/api/health`
- 使用 Free 计算方案即可试用；按 Render 当前规则可能存在冷启动。

也可使用仓库根目录的 `render.yaml`。不需要配置任何全站共用的 DeepSeek 密钥。

## 密钥与数据
API Key 只保留在玩家页面的运行内存里；刷新或关闭页面后需要重新输入。
网站后端仅在请求期间使用玩家提交的密钥，向 DeepSeek 官方固定地址转发；不写入文件、不记录请求正文、不共享密钥。
聊天和剧情请求会发送必要的公司资料、经营摘要和近期故事记忆。API 费用由玩家自己的账户承担。
存档保存在当前浏览器，JSON 导出不包含密钥。跨设备不自动同步；清理浏览器数据前应导出备份。
服务缓存仅包含公开程序和案例文件，不缓存AI请求或响应。

## 内容边界
案例参考 LOOTDROP 公开资料。原站含 AI 辅助分析，部分状态或归因未经独立核实；每张卡保留来源与状态说明。
100张卡是简短学习档案，不是100篇深度历史研究，也不是LOOTDROP全站镜像。
经营剧本、学习问题、重建练习和数值规则为原创模拟设定。停运、收购和重组不自动等同于公司破产。
本项目不声称获得 LOOTDROP 官方授权或背书。正式销售前仍应核实拟用内容的事实及商用许可。

## 验证
运行 `npm test`，覆盖20个剧本、100例来源、DIY输入、资金结算、剧情结构与缓存、自拟行动、旧存档兼容和公开接口边界。

## 架构与修改边界

```text
浏览器界面
  app.mjs                     导航、交互与当前局面
  view-home/library/journal/review.mjs  各屏幕模板
  ui-kit.mjs / styles.css      公共视觉组件与样式
       │
  engine.mjs                  纯经营结算与存档校验
  content / case-expansion / scenario-expansion.mjs  内容数据
  diy.mjs / story-schema.mjs   DIY资料与AI剧情契约
       │
  platform.mjs → server.cjs    同源网络边界与资源服务
                    ├ access.cjs    每日码验证、签名月卡与试玩额度
                    ├ ai.cjs        会议桌对话
                    └ director.cjs  剧情和自拟行动
                         → DeepSeek 官方接口
```

新增案例不需要修改服务器；调整经营规则不依赖模型提示词；更换页面模板不触碰结算；AI服务异常不会影响无需 AI 的经营结算。页面模板显式接收所需状态，服务器不参与浏览器存档持久化。存档结构与AI响应经过独立校验，避免文本生成直接修改财务。

## 每日激活码与月卡

首页及所有页面顶部显示激活入口、剩余试用回合或月卡到期时间。每个当前浏览器共体验 3 次经营结算，重开、刷新和导入游戏存档不重置。预设选择和 DIY 自拟行动统一经 `/api/game/turn` 在服务器结算并扣除试用额度；失败不扣除，完全相同请求可安全重试。用完后仍能查看案例、存档和复盘。

沿用用户提供的万界人生模拟器年表：366 个月-日对应的固定码，每年同日循环。按服务器时间与 Asia/Shanghai（UTC+8）判断当天码，只有当天能激活；从激活时刻起有效 30×24 小时。有效期间不限回合，重复激活不叠加时间；到期后可用新日期的码重新激活 30 天。

Render 服务的环境变量为配置来源：

- `ACTIVATION_CODES_JSON`：月-日到激活码 SHA-256 小写十六进制摘要的 JSON 对象。必须包含全部 366 天；完整明文年表只交由卖家保管，不提交仓库或公开给浏览器。
- `ACCESS_SIGNING_SECRET`：至少 32 字符的随机密钥，用于签名 HttpOnly、SameSite=Lax 的月卡和试用凭证。生产环境缺失时拒绝启动。更新应用时必须保留该密钥，否则旧月卡无法验证。
- `MONTHLY_ACTIVATION_CODE`：仅供本机测试的固定码兼容项，正式环境不设置。

凭证保存在当前浏览器的 Cookie 中，游戏存档仍由原存档模块保存在 localStorage，导出游戏不会导出月卡。服务重启后最新签名凭证仍可验证。请勿清理网站数据、使用无痕模式或指望自动跨设备同步。

本版本没有账号、订单绑定或持久化购买数据库。清空全部站点数据、无痕模式或换浏览器可以重新获得试用；持有码的用户在当天可以转发激活。签名凭证避免直接篡改额度或期限，但这不是严格防盗版、设备绑定或交易核销系统。进程内缓存会阻止旧凭证倒退；服务重启后不能识别用户主动恢复的旧凭证副本。需要严格商业核销时，应增加账号与持久化授权账本。

自动发货说明中的激活码需要卖家按北京时间每天更新，不会由本项目自动修改店铺。此项目的月卡权限独立于万界人生模拟器；码值相同不会同步两边的激活状态。
